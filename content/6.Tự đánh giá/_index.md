# 6. Self-Assessment

During my studies, research, and implementation of the project **“Design and Deployment of a Secure Web Server on AWS Using VPC, EC2, S3, and CloudWatch”**, I had the opportunity to strengthen my knowledge of cloud computing, gain hands-on experience with AWS services, and develop essential skills for a professional working environment.

Through the process of building a Web Server, configuring firewalls, managing IAM access permissions, protecting data stored in Amazon S3, and monitoring the system with Amazon CloudWatch, I gained a better understanding of how AWS services can be integrated to build a secure, reliable, and cost-effective system.

In addition to technical knowledge, working on this workshop helped me improve my teamwork, time management, problem-solving, and independent learning skills.

## Areas for Improvement

Although I gained valuable knowledge and skills throughout the project, I recognize several areas where I still need to improve:

- **Technical knowledge:** Deepen my understanding of AWS system architecture, especially network security, access management, and resource optimization.

- **Hands-on experience:** Continue deploying, configuring, and managing AWS services to improve my ability to apply theoretical knowledge in real-world scenarios.

- **Problem-solving skills:** Improve my ability to analyze errors, review system logs, and troubleshoot issues related to VPC, EC2, S3, and CloudWatch.

- **Time management:** Develop more effective work plans, allocate sufficient time to each task, and proactively test the system.

- **Communication and teamwork:** Strengthen communication, knowledge sharing, and collaboration with other team members.

- **Technical documentation:** Continue improving my ability to write technical reports, create workshop documentation in Markdown, and produce clear, easy-to-follow deployment guides.

In the future, I will continue learning, strengthening my AWS cloud computing knowledge, and developing the skills I still need to improve so that I can apply them effectively in real-world projects.
