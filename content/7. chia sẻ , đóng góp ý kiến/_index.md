# 7. Sharing and Feedback

## General Impressions and Evaluation

### 1. Learning and Working Environment

During the research and implementation of the project **“Design and Deployment of a Secure Web Server on AWS Using VPC, EC2, S3, and CloudWatch”**, I had the opportunity to experience a learning environment that emphasized initiative, hands-on practice, and independent research.

In addition to studying theoretical concepts, I developed the ability to apply my knowledge to a specific problem, from designing the architecture to configuring, testing, and documenting the deployment results.

Building a simple website with login, document upload, and download features helped me better understand how AWS services work together to support a real-world application.

Through this experience, I realized that independent learning, consulting technical documentation, and verifying results are essential to completing tasks effectively.

### 2. Support from Mentors and Team Members

Throughout the workshop, knowledge-sharing sessions, deployment suggestions, and discussions with my teammates provided valuable perspectives on solving technical problems.

In particular, when working with VPC configurations, Security Groups, Network ACLs, IAM permissions, and Amazon S3 data security, exchanging ideas and comparing approaches helped me better understand the purpose of each configuration step.

I learned that building a reliable system requires more than making it work. It also involves explaining why particular services were selected, how access permissions are defined, and how the system's security can be verified.

These experiences helped me strengthen my analytical thinking and technical communication skills.

### 3. Relevance of Practical Tasks to Academic Knowledge

The project was closely related to my academic knowledge of computer networking, system administration, information security, and web application development.

While deploying the system on AWS, I recognized how familiar concepts such as subnets, route tables, firewalls, servers, storage, and monitoring are applied in a cloud computing environment.

Through Amazon VPC, I gained a better understanding of network organization and traffic control.

Amazon EC2 was used to host the Web Server; Amazon S3 provided document storage; IAM supported access management based on the principle of least privilege; and Amazon CloudWatch helped monitor system activity.

Integrating these services enabled me to see the connection between what I had learned in class and the practical requirements of a security-focused web system.

### 4. Learning Opportunities and Personal Development

Developing the workshop gave me opportunities to improve my self-learning skills by studying AWS documentation, practicing in the AWS Management Console, and testing individual system components.

Challenges such as incorrectly configured access permissions, blocked network connections, or an application being unable to access stored data helped me practice identifying root causes and finding appropriate solutions.

Beyond technical skills, I also learned how to create instructional materials in Markdown, organize deployment steps clearly, and document screenshots so that others can follow the process.

In the future, I hope to explore AWS security, deployment automation, and cloud resource cost optimization in greater depth.

### 5. Teamwork and Collaboration

Since the project was carried out by a **team of four members**, dividing responsibilities and agreeing on shared configurations were essential.

The tasks covering **VPC and Firewall, EC2 and Web Server, S3 and Data Security, and CloudWatch and Monitoring** were assigned separately, but they were interconnected parts of a complete system.

Through this collaboration, I gained a better understanding of the importance of communication, consistent resource naming conventions, appropriate access permissions, and testing connections between services before integration.

I also learned that each member should take responsibility for their assigned work while remaining willing to support others to ensure the team stays on schedule.

### 6. Program Evaluation and Suggestions for Improvement

I appreciate the learning approach that combines theoretical research with hands-on workshop development.

Having the opportunity to select solutions, deploy the system, and present the results helped me develop a deeper understanding than studying documentation alone.

The project also helped me develop a security-first mindset, considering security from the design stage rather than only checking it after the system had been completed.

To make future learning and workshops even more effective, I would welcome additional sessions on practical scenarios such as troubleshooting IAM permission issues, testing Security Groups and Network ACLs, protecting S3 data, analyzing CloudWatch logs, and managing AWS costs.

These topics would help learners better understand how to operate, secure, and optimize cloud-based systems.

Overall, this project provided valuable experience in AWS technologies, hands-on implementation, teamwork, and technical documentation.

It has established a foundation for me to continue developing my cloud computing knowledge and applying it to real-world projects in the future.
