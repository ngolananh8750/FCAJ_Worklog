### Mục tiêu tuần 5:

* Cài đặt và cấu hình dịch vụ Web Server Nginx trên máy chủ EC2.
* Cấu hình Tên miền (Domain Name) trỏ về địa chỉ IP công khai của máy chủ.

### Các công việc cần triển khai trong tuần này:

| Thứ | Công việc | Ngày bắt đầu | Ngày hoàn thành | Nguồn tài liệu |
| :--- | :--- | :--- | :--- | :--- |
| 2 | SSH vào EC2, cài đặt dịch vụ Nginx và quản lý trạng thái hoạt động | | | |
| 3 | Tạo thư mục giao diện Web cơ bản và tùy biến trang HTML mẫu tại `/var/www/html` | | | |
| 5 | Cấu hình bản ghi A Record của Tên miền cá nhân trỏ về Public IP của máy chủ EC2 | | | |

### Kết quả đạt được tuần 5:

* Vận hành thành công Nginx Web Server trên hệ điều hành Linux.
* Người dùng có thể truy cập thành công giao diện trang web thông qua Tên miền cá nhân.
